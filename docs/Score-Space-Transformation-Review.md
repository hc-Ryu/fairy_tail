## 1. 개요

본 리뷰는 `score_space_transformation.pdf` 문서의 수학적 유도가 **x에서 예측한 score function을 d 공간(설계변수)으로 변환하는 방법의 근거로서 타당한지** 검증한다.

### 문서의 최종 공식

$$\frac{\Delta g(x_0)}{\Delta d} \approx -\frac{x_0}{d_1} f'(x_0)$$

- f(x): 일반 함수, E[x] = d₁
- 스케일링: r = d₂/d₁, g(y) = f(y/r) = f(d₁/d₂ · y)
- Chain rule로 d₂ = d₁에서 미분

## 2. 발견된 문제

### [ERROR] Jacobian 항 누락 (확률밀도 적용 시)

확률변수 X를 Y = rX로 스케일링할 때, 올바른 밀도 변환은:

$$p_Y(y) = \frac{1}{r} \cdot p_X(y/r)$$

문서는 g(y) = f(y/r)만 사용하여 **1/r 인자(Jacobian)를 반영하지 않음**.

Log-density에 적용하면:

$$\log p_Y(y) = \log p_X(y/r) - \log r = \log p_X(y/r) - \log(d_2/d_1)$$

d₂에 대해 미분 시:

| 항 | 출처 | 값 (d₂=d₁) |
|---|------|------------|
| **Shape 성분** (문서가 유도) | ∂/∂d₂ [log p_X(d₁/d₂ · y)] | -(x₀/d₁) · S_X(x₀) |
| **Volume 성분** (문서에 누락) | ∂/∂d₂ [-log(d₂/d₁)] | **-1/d₁** |

합산하면:

$$S_d(x_0) = -\frac{x_0}{d_1} S_X(x_0) + \left(-\frac{1}{d_1}\right) = -\frac{1}{d_1}(1 + x_0 \cdot S_X(x_0))$$

이것이 DD-RDO의 완전한 **Score Space Transformation Equation**이다.

### [WARNING] 적용 범위 불일치

문서 제목은 "Function Value Sensitivity"로, 일반 함수에 대한 민감도 유도이다. Score function 변환(log-density의 매개변수 미분)에 직접 적용하면 Jacobian 항이 빠져 **불완전한 변환**이 된다.

단, Defense 측 주장에 따르면: 문서가 의도적으로 chain rule 성분(Shape)만 유도하고, Jacobian 보정은 별도 단계로 상정했을 가능성이 있다.

### [INFO] 예제의 한계

f(x) = x²는 확률밀도함수가 아니므로 score function 변환의 검증 예제로는 부적합하다. Jacobian 항의 필요성은 밀도 함수 예제에서만 명확히 드러난다.

## 3. 수학적 유도 검증

### 3.1 Chain Rule 유도 (문서 Section 3)

$$u(d_2) = \frac{d_1 x_0}{d_2}, \quad g(d_2) = f(u(d_2))$$

$$u'(d_2) = -\frac{d_1 x_0}{d_2^2} \quad \checkmark$$

$$g'(d_2) = f'(u(d_2)) \cdot u'(d_2) \quad \checkmark$$

$$d_2 = d_1 \text{ 대입}: \quad g'(d_1) = f'(x_0) \cdot \left(-\frac{x_0}{d_1}\right) = -\frac{x_0}{d_1} f'(x_0) \quad \checkmark$$

**판정: 수학적으로 정확.** Chain rule 적용에 오류 없음.

### 3.3 DD-RDO 공식 복원 경로

문서 결과를 확률밀도에 적용하여 DD-RDO 공식을 복원하는 완전한 경로:

```
Step A (문서의 기여): Chain Rule → -(x₀/d₁) · S_X(x₀)      [Shape]
Step B (누락된 보정):  Jacobian  → -1/d₁                    [Volume]
────────────────────────────────────────────────────────────
Step C (합산):         S_d(x₀)  = -(1/d₁)(1 + x₀ · S_X(x₀))  [DD-RDO 완전 공식]
```

2. **가우시안 예제 추가**: f(x) = log N(x; d, σ²)를 사용하여:
   - Score: f'(x₀) = -(x₀ - d₁)/σ²

   - Jacobian 추가: + (-1/d₁)
