  1. Forward Pass — 소성 중립축(PNA) 계산 오류 [ERROR]                                                                                                                          

  

  문제: bisection 조건 F_tens = F_comp이 모멘트 평형을 찾음, 소성 중립축이 아님.



  # 현재 코드 (모멘트 평형 = 탄성 중립축)

  F_tens = Σ t·fy·max(y - y_mid, 0)   # 힘×거리 = 모멘트

  F_comp = Σ t·fy·max(y_mid - y, 0)



  # 올바른 PNA (힘 평형)

  F_T = Σ_{y_i > y_mid} t_i·fy_i     # 인장 합력

  F_C = Σ_{y_i < y_mid} t_i·fy_i     # 압축 합력



  수학적 증명: F_tens = F_comp → y_pna = Σ(t·fy·y) / Σ(t·fy) = 가중 도심(elastic NA)



  수치 결과:

  비대칭 단면 (t=[10,5,20] mm, fy=355 MPa):

    탄성 NA (코드): y = 92.86 mm

    소성 NA (올바름): y = 150.00 mm

    Mp 오차: 14.29%  (811,429 vs 710,000 Nmm)

  2. Backward Pass — IFT dg/dy_i 부호 오류 [ERROR]



  문제: g = F_tens - F_comp에서 압축 구역(y_i < y_pna)의 편미분 부호가 반대.



  # 현재 코드 (부호 오류)

  dg_dy = sign(y - y_pna) * t_flat * fy_flat   # 압축: -t*fy (틀림!)



  # 올바른 계산

  # y_i < y_pna → g 기여: -t_i·fy_i·(y_pna - y_i)

  # ∂g/∂y_i = -t_i·fy_i·(-1) = +t_i·fy_i  (항상 양수!)

  dg_dy = t_flat * fy_flat  # 부호 없음



  물리적 의미 오류:

  dy_pna/dy_i 코드: [압축: -0.5, 인장: +0.5]  (압축 노드 올리면 y_pna 내려감?!)

  dy_pna/dy_i 올바름: [압축: +0.5, 인장: +0.5]  (모든 노드가 y_pna 올림)



  자체 일관성 테스트 결과:

  비대칭 두께            16.1%

  5. 권장 수정 (우선순위 순)



  Option A: stop-gradient (최소 수정) — 물리 정확도 중간, backward 일관성 확보:

  # backward에서 indirect 항 제거 (y_pna에 stop-gradient)

  dMp_dy = direct  # = t_flat * fy_flat * s



  Option B: force-balance bisection (권장) — 올바른 물리 + 올바른 IFT:

  # forward: 힘 평형으로 변경

  F_T = torch.sum(t_flat * fy_flat * (y > y_mid).float())

  F_C = torch.sum(t_flat * fy_flat * (y < y_mid).float())



  # backward: dg/dy 부호 수정

  dg_dy = t_flat * fy_flat  # 항상 양수 (부호 없음)
