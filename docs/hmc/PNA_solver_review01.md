코드 리뷰 결과: 간접항 비소멸 문제 상세 분석                                                                                                                         
                                                                                                                                                                         핵심 문제: Forward-Backward 불일치                                                                                                                                                                                                                                                                                                          
  # Forward: 모멘트 평형 탐색 (← 이것이 근본 원인)                                                                                                                     
  F_tens = sum(t * fy * clamp(y - y_mid, 0))  # 힘×거리 = 모멘트  
  F_comp = sum(t * fy * clamp(y_mid - y, 0))  # F_tens = F_comp → 탄성 NA

  # Backward: 힘 평형 가정으로 설계됨
  indirect = -sum(t * fy * s) * dy_pna_dy      # ← 이 항이 소멸해야 한다고 암묵적으로 가정

  ---
  [WARNING] 간접항 비소멸 — 수학적 완전 증명

  1. 소멸 조건 도출

  indirect 항의 계수를 분해하면:

  Σ(t·fy·s) = Σ(t·fy·sign(y_i - y_pna))
             = Σ_{y_i > y_pna}(t_i·fy_i) - Σ_{y_i < y_pna}(t_i·fy_i)
             = F_T - F_C  (인장 합력 - 압축 합력)

  소멸 조건: F_T - F_C = 0 ↔ 힘 평형 ↔ 진정한 PNA

  2. 현재 코드가 탄성 NA를 찾는다는 증명

  bisection 조건 F_tens = F_comp를 전개:

  Σ t_i·fy_i·max(y_i - y_mid, 0) = Σ t_i·fy_i·max(y_mid - y_i, 0)
  ⟺  Σ t_i·fy_i·(y_i - y_mid) = 0          [+ 항과 - 항 상쇄]
  ⟺  Σ(t_i·fy_i·y_i) - y_mid·Σ(t_i·fy_i) = 0
  ⟺  y_mid = Σ(t_i·fy_i·y_i) / Σ(t_i·fy_i)   = 가중 도심 (탄성 NA)

  이는 힘 평형(Force balance)이 아닌 면적 1차 모멘트 평형, 즉 탄성 중립축입니다.

  3. 비대칭 단면 수치 예시

  단면: [하판 t=10/fy=355 @ y=0mm, 웨브 t=5/fy=355 @ y=100mm, 상판 t=20/fy=355 @ y=200mm]

  탄성 NA (코드 결과):
    y_elas = (10·355·0 + 5·355·100 + 20·355·200) / (10+5+20)·355
           = 1,597,500 / 12,425 = 92.86 mm

  탄성 NA에서 Σ(t·fy·s):
    y=0   (< 92.86): s = -1 → 기여 = -10·355 = -3,550
    y=100 (> 92.86): s = +1 → 기여 = +5·355  = +1,775
    y=200 (> 92.86): s = +1 → 기여 = +20·355 = +7,100

    Σ(t·fy·s) = -3,550 + 1,775 + 7,100 = +5,325 ≠ 0 → 간접항 비소멸!

  진정한 PNA에서:
  F_T = F_C → PNA가 하판(3550N/mm)과 나머지(8875N/mm) 사이 어딘가
  이산 노드 시스템에서: 이 단면은 분리된 이산 노드이므로 정확한 PNA는
  y_pna ∈ (0, 100) 범위에서 힘 평형 불가 → 노드 사이 위치

  4. 간접항 비소멸이 gradient에 미치는 영향

  indirect 항을 완전히 전개하면:

  indirect_i = -Σ(t·fy·s) · dy_pna_dy_i
             = -(F_T - F_C) · [-(t_i·fy_i·s_i) / (-Σ(t·fy))]
             = -(F_T - F_C) · (t_i·fy_i·s_i) / Σ(t·fy)

  따라서 총 gradient:
  dMp/dy_i = direct_i + indirect_i
           = t_i·fy_i·s_i - (F_T-F_C)·t_i·fy_i·s_i / Σ(t·fy)
           = t_i·fy_i·s_i · [1 - (F_T-F_C)/Σ(t·fy)]

  물리적 해석: gradient가 단면의 불평형 정도 (F_T-F_C)/Σ(t·fy)에 비례하는 스케일 오차를 가짐. Optimizer가 단면 성능 개선이 아닌 불평형 해소 방향으로 왜곡되어 학습.    

  5. Issue 2 (dg_dy 부호 오류)와의 복합 효과

  부호 오류까지 포함한 총 gradient 오차:

  총 오차 Δ = -2(F_T - F_C) - (F_T - F_C)² / Σ(t·fy)
              ├── 1차항: 부호 오류에서 오는 2배 오차
              └── 2차항: 간접항 비소멸에서 오는 추가 오차

  소불평형 ε≈0: Δ ≈ -2ε (1차 지배) → gradient 방향 완전 반전 (∼200% 오차)
  대불평형: 5~33% 실측 오차에 부합

  두 버그가 우연히 상쇄되려면 F_T - F_C = -Σ(t·fy) 조건 필요 → 실무에서 발생 확률 거의 0.

  6. Edge Case: y_pna가 노드 경계에 위치할 때

  s = torch.sign(y - y_pna)  # y_i = y_pna → s=0, 기여 소멸

  bisection에서 y_pna가 특정 노드의 좌표와 일치하면 sign() 불연속 → IFT에 의한 dy_pna/dy_i가 jump → 서브그래디언트 불일치 → optimizer가 step마다 다른 gradient 수신.

  권장 수정

  Option A (최소 수정): stop-gradient
  # backward에서 indirect 항 제거
  dMp_dy = direct  # = t_flat * fy_flat * s
  # y_pna는 상수 취급 → indirect 항 소멸
  → gradient 일관성 확보. forward 물리 오차(탄성 NA)는 잔존.

  Option B (근본 수정, 권장): force-balance bisection
  # forward: 힘 평형으로 변경
  F_T = torch.sum(t_flat * fy_flat * (y > y_mid).float())
  F_C = torch.sum(t_flat * fy_flat * (y < y_mid).float())

  # backward: dg_dy 부호 수정
  dg_dy = t_flat * fy_flat  # 항상 양수 (부호 없음)
  # → Σ(t·fy·s) ≈ 0 at true PNA → indirect ≈ 0 → gradient 정확
  → forward 물리 정확 + backward 일관성 + 간접항 자연 소멸.
