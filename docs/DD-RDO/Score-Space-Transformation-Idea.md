## 1. 문제 정의

- **입력**: Score function w.r.t. 확률변수 x: $S_X(x) = \nabla_x \log p(x)$
- **목표**: Score function w.r.t. 설계변수 d (x의 평균값): $S_d(x) = \frac{\partial}{\partial d} \log p(x; d)$
- **핵심 질문**: $S_X(x)$를 이용하여 $S_d(x)$를 어떻게 계산할 수 있는가?

---

## 2. 핵심 답변: 3가지 변환 경로

d가 분포에 미치는 **기하학적 영향**(위치 이동 vs 척도 변환)에 따라 경로가 나뉜다.

### 2.1 Location Family (위치 가족) — d가 위치 모수일 때

**조건:** $X = d + Z$ (Z는 고정 분포, $E[Z]=0$)

$$p(x; d) = p_Z(x - d)$$

$$\boxed{S_d(x) = -S_X(x)}$$

**적용 예:** Gaussian $N(d, \sigma^2)$, Cauchy$(d, \gamma)$, Logistic$(d, s)$

- 가장 단순하고 정확한 변환
- 평균을 바꾸는 것이 분포를 평행 이동시키는 경우

### 2.2 Scale Family (척도 가족) — d가 척도 모수일 때

**조건:** $X = d \cdot Z$ (Z는 고정 분포, $E[Z]=1$)

$$p(x; d) = \frac{1}{d} p_Z\!\left(\frac{x}{d}\right)$$

$$\boxed{S_d(x) = -\frac{1}{d}\bigl(1 + x \cdot S_X(x)\bigr)}$$

이것이 **DD-RDO Score Space Transformation Equation**이며, 두 성분으로 구성된다:

| 성분 | 수식 | 물리적 의미 |
|------|------|------------|
| **Shape** (Chain Rule) | $-\frac{x}{d} S_X(x)$ | 함수값의 민감도 (score_space_transformation.pdf에서 유도) |
| **Volume** (Jacobian) | $-\frac{1}{d}$ | 확률 보존에 의한 밀도 보정 |

**적용 예:** Exponential$(1/d)$, Rayleigh$(d)$, Weibull$(d, k)$

### 2.3 General Case (일반적 경우) — Reparameterization

**조건:** $X = g(Z, d)$ 임의의 미분 가능한 변환

$$S_d(x) = \frac{\partial}{\partial d} \log p(x; d)$$

이 경우 직접 유도하거나 **자동 미분(Auto-diff)**을 활용한다.

**실용적 접근:**
- **Exponential Family**: 정준 모수 $\eta(d)$ 관계를 통해 $S_d = \frac{d\eta}{dd} \cdot (t(x) - E[t(x)])$
- **Reparameterization Trick**: $x = g(\epsilon, d)$, $\epsilon \sim q(\epsilon)$로 변환 후 chain rule 적용

## 3. 판별 가이드

```
d = E[X]가 주어졌을 때:

1. 분포의 형태(shape)가 d에 무관한가?
   ├─ YES: p(x;d) = f(x - d) 또는 (1/d)·f(x/d) 형태?
   │   ├─ 평행이동: Location family → S_d = -S_X
   │   └─ 스케일링: Scale family → S_d = -(1/d)(1 + x·S_X)
   └─ NO: General case → 직접 유도 또는 reparameterization
```

**주의:** Gaussian $N(d, \sigma^2)$에서 d는 **위치** 모수 → DD-RDO 척도 공식이 아닌 $S_d = -S_X$ 적용

## 4. 아이디어 순위

### 1위: Location-Scale 분류 프레임워크 (권장)
- **장점:** 수학적으로 엄밀, 계산 효율적 ($S_X$ 재활용), Fisher Information과 일관
- **단점:** 분포가 어느 가족에 속하는지 사전 판별 필요
- **실현 가능성:** 높음 — 대부분의 공학적 확률 분포가 location-scale 가족

### 2위: Exponential Family 정준 모수 접근
- **장점:** 자연스러운 충분통계량 활용, 정보기하학적 해석 가능
- **단점:** Exponential family에 한정, non-exponential 분포 불가
- **실현 가능성:** 중간

### 3위: Score Matching + Auto-diff
- **장점:** 분포 가족 판별 불필요, 완전 일반적
- **단점:** 계산 비용 높음, $S_X$를 재활용하지 못함
- **실현 가능성:** 높음 (구현 복잡도는 높으나 범용적)

## 5. 고려 사항

- **Jacobian 항의 중요성**: 이전 리뷰(Score-Space-Transformation-Review.md)에서 지적된 바와 같이, 확률밀도 변환 시 Volume 항 $-1/d$을 반드시 포함해야 함
- **다변수 확장**: Jacobian이 행렬식(determinant)으로 확장됨
- **근사 오차 전파**: Score matching으로 학습된 $S_X$가 근사값일 경우, 변환 오차가 $S_d$에 전파됨
- **수치 안정성**: $d \to 0$ 일 때 $1/d$ 항이 발산 → $\epsilon$ 보정 또는 로그 스케일 연산 고려
